# ♟️ Chess UI

A lightweight, interactive chess interface built with vanilla HTML, CSS, and JavaScript.

Designed as a simple browser-based chess experience with a clean UI and minimal dependencies.

## ✨ Features

* Interactive chess board
* Piece movement
* Responsive interface
* Web Worker integration
* No frameworks or external dependencies

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Web Workers

## 🚀 Run Locally

```bash
git clone https://github.com/abdullah2036/chessUI.git
cd chessUI
```

Open `index.html` in your browser.
